# Desk prototype and visual design

The [original three-page team plan](team-plan.pdf) records the proposed operator workflow, board responsibilities, model authoring, acceptance tests and initial references. Read it as a design proposal. The [motor simulator](motor-simulator.html) is an early self-contained browser demo. Open the file locally, start the simulated motor, then query its startup or change the active profile.
