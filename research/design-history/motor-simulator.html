How the profiles work

Each profile contains two numerical weights defining an expected range for startup duration. The model multiplies the measured duration by the first weight, adds the second, and checks whether the result falls between −1 and +1. Motor A expects 1.0–1.4 seconds. Motor B expects 0.3–0.6 seconds. Switching profiles rescores the current startup.

The simulator generates 200 readings per simulated second. The detector measures vibration strength over 0.1-second windows and waits for two consecutive quiet windows before declaring the startup settled. The graph shows up to four seconds. Switching tabs can pause the simulation clock.
